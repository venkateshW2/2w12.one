2w12.one — email signature

Two variants below. Select the rendered signature, copy, and paste into your mail client's signature box — or paste the HTML source if your client takes it.

The wordmark is a GIF, and it has to be. Every mail client strips @keyframes, so the site's CSS glitch cannot travel. Outlook on Windows renders GIFs through Word and shows only the first frame — which is why frame 0 is the clean wordmark. Worst case it degrades to a correct static logo.

A · Dark card — recommended

The wordmark's background is #0c0c0c and cannot be transparent — the glitch works by painting displaced copies with the background so they occlude what's beneath. On a dark card there is no seam, and it reads the same in light and dark mail.

Before you paste

  1. Replace REPLACE@2w12.one with the real address — it appears twice per variant (the visible text and the mailto:).
  2. The GIF must be live at https://2w12.one/images/email/2w12-wordmark.gif first. It is committed, so it goes up with the next deploy. An email keeps fetching that URL forever — if the path ever moves, every signature already sent breaks.

Per client

  1. Gmail — Settings ▸ See all settings ▸ Signature. Paste the rendered block (select it above and copy), not the source; Gmail's box is WYSIWYG and will show HTML as literal text.
  2. Apple Mail — Settings ▸ Signatures, paste the rendered block. If it loses the layout, drag-select from the preview above rather than copying source.
  3. Outlook web — Settings ▸ Mail ▸ Compose and reply, paste rendered.
  4. Anything that takes raw HTML — use the textarea source.

Known limits, none of which fail loudly

  1. Images are blocked by default in many clients, so the wordmark may not appear at all on first open. That is why alt="2w12.one" is set and the name and link are real text — the signature still works with every image off.
  2. Outlook desktop shows frame 0 only. Deliberate: frame 0 is clean.
  3. Dark mode can invert text in some clients. Variant A is already dark, so it survives that better than B.
  4. No web fonts. Mail clients ignore @font-face, so the text is Arial/Helvetica. Only the wordmark is real Inter — because it is an image.

Regenerating

npm run make:signature — rebuilds the GIF and the still from assets/fonts/Inter-ExtraBold.ttf. Editing the timeline or slip bands in scripts/make-email-signature.js changes the glitch; keep frame 0 clean.
